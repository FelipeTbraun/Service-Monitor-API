# service-monitor-api

> ⚠️ Projeto de estudos, em desenvolvimento.

API em Python (FastAPI) para cadastrar serviços (sites e APIs) e verificar se estão no ar.

## Status

- [ ] API base (cadastro e listagem de serviços)
- [ ] Banco de dados (SQLite)
- [ ] Checagem manual de um serviço

## Como rodar

    pip install -r requirements.txt
    uvicorn app.main:app --reload

Documentação interativa em http://127.0.0.1:8000/docs
